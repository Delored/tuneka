# Tuneka: desktop UI

## Орієнтири

Досліджені інтерфейси та офіційні матеріали:

- [Parabolic](https://github.com/NickvisionApps/Parabolic#-screenshots): бічна навігація, темна тема, видимий прогрес та керування завантаженнями.
- [Downie](https://software.charliemonroe.net/downie/): простий шлях від посилання до файлу; параметри якості й обробки поруч із завантаженням.
- [4K Video Downloader Plus](https://www.4kdownload.com/blog/2023/07/10/introducing-4k-video-downloader-plus/): налаштування формату й якості та робота з добірками в єдиному інтерфейсі.

Це джерела для порівняння патернів, а не рейтинг продуктів. Графіку інших застосунків не використано.

## Рішення

- Чотири зрозумілі розділи в бічному меню; активний розділ виділений м'якою заливкою.
- Спокійні темні поверхні, тонкі контури, заокруглені картки та кнопки. Оливкова, фіолетова й світла палітри зберігаються в налаштуваннях.
- У полі URL є підказка та окрема кнопка вставлення. Підказка не є значенням поля.
- У списках є номери й позначки вибору. Клік перемикає вибір, Space працює з поточним рядком, Ctrl+A вибирає всі.
- Порожні списки пояснюють наступний крок. Декоративна звукова хвиля намальована локально; зовнішні зображення не потрібні.
- Формати й роздільна здатність вибираються заокругленими полями з нативним меню та підтримкою клавіатури.
- Нижня панель має гарантоване місце: тека, основна дія, статус, прогрес, пауза та скасування під ним. Повний текст довгого статусу відкривається кліком.
- При висоті вікна нижче 780 px зникають допоміжні описи й підписи поля URL; заголовки стають компактнішими. Простір повертається списку.

Застосунок залишається нативним Tkinter desktop-застосунком без нових runtime-залежностей.
